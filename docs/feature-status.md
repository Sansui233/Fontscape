## F1 字体扫描和读取

- ✅ 扫描 `C:\Windows\Fonts` 和 `%LOCALAPPDATA%\Microsoft\Windows\Fonts`，支持 TTF / OTF / TTC（多 face）。
- ✅ 解析 Name ID 0–20、中文名、CSS family、字重、可变字体、字符集。细节见 [font-parsing.md](font-parsing.md)。
- ❌ **没有读注册表**。只按目录扫描，所以无法区分已安装和仅存在文件的字体，也识别不了「已禁用」。
- ❌ **没有缓存**。每次启动都全量解析；`font_file_cache` 表已建，但还没用上。
- ⚠️ **解析是串行的**。依赖里有 `rayon`，但没有使用。
- ⚠️ **启动时会扫描两次**：`App` 和 `Sidebar` 各调用了一次 `useFonts()`。
- ⚠️ 判断格式时扩展名区分大小写（`Some("ttf")`），所以 `.TTC` 只会解析第一个 face，`.OTF` 会被标成 TrueType。

## F2 字体启用/禁用

- ❌ `commands.rs::toggle_font` 只打印日志，然后返回 `Ok`。
- ⚠️ **假成功**：`FontCard` 收到 Ok 后会调用 `updateFontStatus`，界面显示已禁用，但系统里什么都没变。
- ⚠️ 系统字体保护名单在 `scanner.rs::is_system_font`，内容是 Segoe UI / Microsoft YaHei / SimSun / Tahoma。设计文档里的 Arial 不在名单中。
- ❌ 备份、`WM_FONTCHANGE`、批量操作都没有。设计方案见 [font-enable-disable.md](font-enable-disable.md)。

## F3 字体预览

- ✅ **Grid**：按 family 分组，用虚拟滚动；窗口宽度 <640 / <1024 / ≥1024 时分别显示 1 / 2 / 3 列。卡片上有书角数量、状态点和 V（可变字体）标记。
- ✅ **List**：用虚拟滚动。与 Grid 只有字体展示外观不同，右键菜单、多选、预览控制都相同。
- ✅ **预览控制**：标题栏预览框右侧的字号按钮里调字号（12–72）、字重和斜体，Grid、List、详情页共用同一组设置。
- ✅ **实时预览**：Topbar 的预览文本输入带 500ms 防抖；字体里没有的字形用 `□` 替代，避免浏览器回退到其他字体。
- ✅ 点击卡片会进入 `/family/:name` 详情页，Grid 和 List 都会恢复滚动位置。
- ⚠️ **Paper View**：需求里有，但还没定义。现在最接近的是 List 视图。
- ✅ **本地化名称**：后端提取 zh-Hans / zh-Hant / ja / ko 四种名称，存入 `localized_names`。设置中可选「本地化优先」或「English」：本地化优先时按界面语言显示对应名称。搜索会匹配所有语言的名称。
- ⚠️ **性能隐患**：每张卡片、每一行都会调用一次 `check_glyphs_in_font`，后端每次都要完整读取并解析字体文件。中文字体一般有 10–30MB，预览文本一改，所有可见卡片都会重新读一遍。
- ❌ 字体懒加载没有做。系统字体通过 `local` family 名由 WebView 按需加载，是否需要再做懒加载，等实测后再决定。

## F4 字体详细信息

- ✅ `RightSidebar`：显示常用元数据，可以打开文件位置，可拖拽调整宽度（240–600px）。
- ✅ `FontInfoModal`：完整列出 Name ID 0–20，以及格式、大小、语言、脚本等信息。
- ✅ 预览模板：按字符集显示英文、简体、繁体、日文、韩文样张，可直接编辑；有字号、字重、斜体控制。
- ⚠️ 已定义的 `numbers` 模板没有使用；没有符号和 emoji 模板。
- ❌ 导出字体样本没有做。
- ⚠️ `FontInfoModal` 里的「Added」显示的是扫描时间，不是安装时间。

## F6 字体分类和过滤

- ✅ **语言检测**：代表字启发式，见 [font-parsing.md](font-parsing.md)。
- ✅ **类型分类**：`font/classifier.rs`，依次看名称关键词（中英文）→ isFixedPitch → PANOSE → sFamilyClass → Unknown。分为 Serif / Sans Serif / Monospace / Handwriting / Decorative / Unknown；楷体、隶书归入 Handwriting。
- ✅ **过滤**：Grid 和 List 共用 `lib/font-filter.ts`。同一项内为 OR，不同项之间为 AND；Language 与 Category 必须由同一个 face 满足。
- ✅ **Filter 面板**：标题栏的 Filter 按钮显示已选数量，点开后可多选、查找选项、清除；已选条件以 chip 形式显示在内容区顶部，可以逐个移除或保存为命名 Filter。
- ✅ **命名 Filter**：在 Sidebar 中右键可编辑或删除，写入 SQLite，重启后保留。Language preset 也能编辑或删除。
- ✅ **文件夹**：「已存筛选」支持无限嵌套的文件夹（schema v3：`filter_folders` 表，`saved_filters.folder_id` 列）。
  - 在分组标题或文件夹上右键可新建筛选 / 新建文件夹；文件夹还可重命名、移到顶层、删除。
  - 删除文件夹时可选：只删文件夹、内容移到上一级（默认），或连同全部内容一起删除。
  - 筛选和文件夹都能拖动；拖到分组标题上表示移到顶层。不能把文件夹拖进它自己的子文件夹（前后端都有校验）。
  - 分组底部是「+ 新建筛选」。
- ✅ **文本条件**：Name contains 匹配所有名称，包括本地化名；Tag contains 匹配该家族任一标签名（子串、不区分大小写）。
- ✅ **标签**：打在字体家族上（schema v4：`tags`、`font_tags`）。
  - 打标签的入口：卡片 / 列表行右键「标签…」、多选工具条「标签…」、详情页标签行（可移除 / 添加）。
  - 标签选择器同时支持多选：每个标签显示全部有（✓）、部分有（–）或没有；输入框兼作查找和新建。
  - 侧栏 Tags 分组：点击按该标签筛选，右键可重命名或删除（需确认）；分组底部是「+ 新建标签」。
- ✅ **启动与设置**：一次 `bootstrap_app` 调用返回所有数据；当前条件、视图、侧栏状态和预览偏好会自动保存，保存失败时弹出 toast。
- ⚠️ **搜索**：只做子串匹配，会检查 family 内所有 face。`fuse.js`、`pinyin-pro` 还没用上。
- ❌ 字体解析缓存（`font_file_cache` 还没用到，每次启动都全量解析，已改为 rayon 并行）。

## F7 右键菜单

- ✅ `ContextMenu` 通过 portal 渲染到 body，会自动避开窗口边缘，按 Esc 或点击外部可以关闭。
- ✅ **Info**：右键菜单和卡片 hover 时出现的 ⓘ 按钮都能打开 `FontInfoModal`。
- ✅ **Multi-select**：能进入多选模式并选中当前项，卡片 / 列表行上显示复选框，点击可切换选中。
- ⚠️ **多选工具栏**：显示数量和 Done 按钮；批量启用、禁用、删除都没有。
- ⚠️ **Disable/Enable**：菜单文字会随状态变化，系统字体项是灰的；但它调用的是 F2 的空实现。

## UI / 布局

- ✅ **L 形框架**：侧栏和标题栏共用半透明外框（底下是 Windows Acrylic 模糊，窗口 `transparent: true` + `windowEffects: acrylic`；系统关闭「透明效果」时通过 `prefers-reduced-transparency` 改回实色），内容区是嵌在里面的白色面板，左上角圆角。去掉了原生标题栏，自绘最小化、最大化、关闭按钮，空白处可以拖动窗口。
- ✅ **单行标题栏**：从左到右依次是：返回、当前标题和数量（Filter 名或 All Fonts）、可展开的搜索、Filter、预览文字和字号、Grid/List 切换（这四项只在 Grid/List 页显示）、设置（仅侧栏收起时）、窗口按钮。设置和「显示侧栏」按钮出现/消失时宽度过渡，相邻按钮平移。
- ✅ **Sidebar**：macOS 风格，行高 26px；All Fonts / Languages / Saved Filters / Tags 四组，分组可以折叠；展开时淡入滑入，底部是设置按钮；侧栏收起后，鼠标移到窗口左边缘会滑出浮层。
- ✅ **卡片**：预览区高度跟随字号；信息区两行：名称 + VAR 标记、类型 · 字形数 · 格式，语言缩写靠右；hover 时只加深边框和阴影。
- ✅ **详情页**：进入时有 220ms 的淡入上移动画。
- ✅ **快捷键**：Ctrl/⌘ + F 聚焦搜索（折叠时自动展开），Ctrl/⌘ + P 聚焦预览文字，Esc 退出输入框焦点。
- ✅ **设置弹窗**：侧栏底部按钮（侧栏收起时在标题栏）或 Ctrl/⌘ + , 打开。包含以下几组：
  - 外观（跟随系统 / 日间 / 夜间）、字体名称语言（中文优先 / English）；
  - 字体库统计、重新扫描、扫描目录；
  - 数据库位置（可在资源管理器中打开）；重建数据库，先把原文件备份为 `fontscape.db.bak-<时间戳>`；
  - 快捷键、版本信息。
- ✅ 数据库打不开时，启动失败页也提供「Reset database」入口。
- ✅ **i18n**：界面支持 English、简体中文、日本語、한국어 和「跟随系统」。语言、类型、状态等数据值和后端错误 code 都会翻译。`<html lang>` 跟随界面语言，这会影响汉字在回退字体中的字形选择。中文产品名待定，目前所有语言都显示「Fontscape」。
- ✅ **多选**：勾选框在卡片右上角，是圆形的。
- ✅ **窗口按钮**：与标题栏图标同一风格。悬停最大化按钮 0.5 秒后模拟 Win+Z，唤出 Win11 的分屏布局浮层。

## 测试与质量

- ✅ `cargo test`：18 个测试全部通过，其中 12 个单元测试、6 个集成测试。集成测试依赖本机已安装的字体（如 LXGW WenKai），换一台机器可能失败。
- ✅ `tsc --noEmit` 通过。前端没有测试，按约定由用户手动验证。
- ⚠️ 有几个依赖装了但没用：`immer`、`fuse.js`、`pinyin-pro`、`@radix-ui/*`、`rayon`、`dashmap`。

## 建议优先级

1. **字体解析缓存**：增量扫描，降低启动耗时（plan 文档 Phase 2 的剩余部分）。
2. **glyph 检查加缓存或改成批量接口**：卡片更密之后，调用次数也更多了。
3. **注册表读取 + 启用/禁用**（F1 + F2）。
4. **标签、拼音搜索、导出样本、暗色模式切换。**
